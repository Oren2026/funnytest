# v0.6 — 可觀測性系統

日期：2026-05-07

---

## 版本目標

建立完整的可觀測性層，讓系統運作透明化。

---

## 功能清單

### 1. 對話日誌

- **檔案**：`workspace/logs/conversation_YYYYMMDD_HHMMSS.md`
- **內容**：每次 gemma4 的提問、使用者的回答、執行的工具

### 2. 階段轉換日誌

- **檔案**：`workspace/logs/phase_transitions.md`
- **內容**：時間戳、舊階段、新階段、觸發節點數

### 3. 約束變化日誌

- **檔案**：`workspace/logs/constraints.md`
- **內容**：何時新增/刪除約束條件

### 4. 節點圖快照

- **位置**：`workspace/logs/`（每回合結束時）
- **內容**：完整 graph 狀態（XML 格式）

### 5. 對話摘要

- **檔案**：`workspace/logs/session_YYYYMMDD_HHMMSS.md`
- **內容**：每次 session 結束時自動產生摘要

## 實作

```rust
// Observability Logger
struct ObsLogger {
    log_dir: PathBuf,
}

impl ObsLogger {
    fn log_conversation(&self, turn: &ConversationTurn)
    fn log_phase_transition(&self, from: Phase, to: Phase, node_count: usize)
    fn log_constraint_change(&self, constraint: &str, added: bool)
    fn snapshot_graph(&self, graph: &Graph)
    fn generate_session_summary(&self, session_id: &str) -> String
}
```
