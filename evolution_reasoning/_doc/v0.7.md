## 待實作功能 🔨

### Execution & Feedback Loop

**核心問題**：從「知道」到「做到」的鴻溝

- 現在只能生成 Tool Call，無法實際執行並根據結果調整推理
- 缺乏外部執行與回饋驗證循環

### 實作架構

```rust
// src/execution/mod.rs [新建]

/// 執行回饋項目
struct FeedbackItem {
    node_id: String,
    execution_result: ExecutionResult,
    timestamp: DateTime<Utc>,
}

/// 執行結果
enum ExecutionResult {
    Success(String),   // 執行成功，回傳結果
    Failure(String),    // 執行失敗，回傳錯誤
    Timeout,            // 執行逾時
    Pending,            // 執行中
}

/// 執行橋接器
struct ExecutionBridge {
    feedback_queue: Vec<FeedbackItem>,
}
```

### 新增工具

| 工具 | 參數 | 回傳 | 說明 |
|------|------|------|------|
| `execute` | task: String | FeedbackResult | 執行外部命令 |
| `verify` | node_id: String | Bool | 驗證執行結果 |
| `retry` | node_id: String | FeedbackResult | 重試失敗任務 |

### Feedback 流程

```
推理圖 → Plan Node → execute() → Feedback 回傳
                ↓                          ↓
          根據 Feedback 調整推理路線    更新節點狀態
```
