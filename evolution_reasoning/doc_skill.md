## 資料夾結構

```
evolution_reasoning/
├── _wiki/           # 專有名詞說明（300行/詞項）
├── _doc/            # 計劃文件（版本記錄、規劃）
```

## _wiki/ — 專有名詞說明

### 用途

收錄本計劃相關的專有名詞，詳細說明其理論背景、概念定義、應用場景。

### 寫作規範

- 每個詞項 300 行左右
- 使用繁體中文（台灣用語）
- 專有名詞第一次出現時加註英文
- 理論背景為主，不是程式註解

### 檔案命名

```
_wiki/[編號]-[英文名詞].md
例：_wiki/01-reasoning.md
```

### 範例結構

```markdown
# 推理 (Reasoning)

## 定義

推理是指...

## 理論背景

### 演繹推理 (Deductive Reasoning)

...

### 歸納推理 (Inductive Reasoning)

...

## 在本計劃中的應用

Evolution Reasoning Tool 中...

## 相關條目

- [[Graph Structure]]
- [[Node]]
- [[Diverge]]
```

### AI 自動維護連結

- 使用 `[[詞條名]]` 語法建立內部連結
- AI 在寫作時主動引用相關詞條
- 保持連結完整性

## _doc/ — 計劃文件

### 必要檔案

| 檔案 | 說明 |
|------|------|
| `plan.md` | 目前的工作計劃 |
| `v0.1.md` | 第一版規劃 |
| `v0.2.md` | 第二版規劃 |
| ... |以此類推 |
| `todo.md` | 待辦事項 |

### 版本命名規則

- 大版本：v1.0, v2.0
- 小版本：v0.1, v0.2, v1.1, v1.2

### 寫作原則

- 思考型 AI 直接快速寫作
- 不需要追求完美
- 重點是內容完整

## AGENTS.md — AI 協作指南

### 用途

讓其他 AI（subagent、新進 AI）看了就知道該做什麼。

### 必要內容

1. 專案目標（一句話）
2. 目前狀態
3. 正在做的事
4. 如何貢獻
5. 檔案結構
6. 相關資源

## _book/ — 書籍

### 結構

```
_book/
├── 00-catalogue.md      # 目錄
├── 01-chapter-title.md  # 第一章
├── 02-chapter-title.md  # 第二章
├── ...
└── A1-appendix.md       # 附錄一
```

### 目錄格式

```markdown
# Evolution Reasoning Tool 書籍

## 第一部分：基礎概念

- [第一章：什麼是推理](/_book/01-reasoning.md)
- [第二章：節點系統](/_book/02-nodes.md)

## 第二部分：系統架構

- [第三章：發散引擎](/_book/03-diverge.md)
- [第四章：收斂引擎](/_book/04-converge.md)

## 附錄

- [附錄 A：名詞解釋](/_book/A1-glossary.md)
```

### 寫作規範

- 每章 300 行以上
- 繁體中文
- 專有名詞加註英文

## README.md — 專案總覽

每個子資料夾都要有。

```markdown
# 資料夾名稱

## 用途

...

## 主要程式

- `xxx.py` — 說明
- `yyy.rs` — 說明

## 相關檔案

- [[相關詞條]]
- [[相關程式]]
```
