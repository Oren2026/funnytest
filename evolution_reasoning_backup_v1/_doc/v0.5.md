## 長期記憶系統

### 設計

**位置**：`workspace/memory/`

**目標**：跨 Session 持久化，不只是 workspace

### 實作

```rust
// src/memory/mod.rs
struct MemoryManager {
    base_path: PathBuf,
}

impl MemoryManager {
    // 儲存感興趣的主題
    fn save_topic(&self, topic: &str, context: &str) -> Result<()>

    // 查詢相關歷史
    fn query(&self, keyword: &str) -> Vec<MemoryEntry>

    // 維護長期記憶（淘汰舊資料）
    fn prune_old(&self, max_entries: usize)
}
```
