# v0.4 — 提問習慣系統

日期：2026-05-07

---

## 版本目標

根據節點數量自動調整 gemma4 的提問風格，建立三階段演化模型。

---

## 三階段模型

### 探索期（Exploration）

- **觸發條件**：節點數 < 3
- **gemma4 行為**：大量提問，了解興趣、價值觀、目標
- **目標**：快速建立上下文，確認問題方向

### 發展期（Development）

- **觸發條件**：節點數 3-10
- **gemma4 行為**：開始建議方向，但仍保持問問題確認
- **目標**：深化理解，逐步收斂方向

### 成熟期（Mature）

- **觸發條件**：節點數 > 10
- **gemma4 行為**：進入發散/收斂模式，主動推動推理
- **目標**：產出具體成果

---

## 實作細節

### 階段轉換邏輯

```rust
fn get_phase(node_count: usize) -> Phase {
    match node_count {
        0..=2 => Phase::Exploration,
        3..=10 => Phase::Development,
        _ => Phase::Mature,
    }
}
```

### 階段轉換日誌

- 檔案：`workspace/logs/phase_transitions.md`
- 記錄：時間戳、舊階段、新階段、觸發節點數

### 系統提示詞動態調整

根據階段，gemma4 的系統提示詞會自動調整：

**探索期**：
```
你是一個好奇的探索者，大量提問來了解使用者的需求。
```

**發展期**：
```
你是一個 consultant，在建議方向的同時保持問問題確認。
```

**成熟期**：
```
你是一個策略分析師，主動推動發散/收斂推理，產出具體成果。
```
