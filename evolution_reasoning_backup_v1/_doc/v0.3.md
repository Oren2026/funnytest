# v0.3 — gemma4 對話介面

日期：2026-05-07

---

## 版本目標

實作 gemma4 對話介面，讓使用者可以透過 CLI 與 Evolution 進行實際對話。

---

## 背景決策

為什麼先做對話介面？

1. 沒有對話介面，整個系統無法實際使用
2. 長期記憶可以靠 gemma4 自己 context window + workspace 持久化
3. 視覺化是輔助，核心是對話流程
4. 約束條件動態調整需要先有對話才能實驗

---

## 功能實作

### Gemma REPL

```rust
// src/cli/gemma_repl.rs
// gemma4 互動對話模式
```

**啟動方式**：
```bash
./evolution_reasoning --对话
```

**流程**：
1. 輸入討論主題（可選：約束條件）
2. gemma4 讀取 workspace/status.xml 取得當前狀態
3. 進入對話迴圈：gemma4 提問 → 使用者回答 → 執行工具 → 更新狀態
4. 輸入 `quit` 結束

### 系統提示詞框架

```
你是一個推理控制器。

當前任務：{task}
狀態摘要：讀取 workspace/status.xml
當前模式：發散（默認）

約束條件：{constraints}

可用工具：
- diverge(node_id, content, count)
- converge()
- save(name)
- load(name)
- output(format: "xml" | "md")
- status()

規則：
- 默認模式為發散
- 當複雜度 > 閾值，自動提醒
- 沒有固定目標，持續探索
- 產出存到 workspace/
```
