# 推理 (Reasoning)

## 定義

推理（Reasoning）是指從已知的前提或資訊出發，透過邏輯運算得出新結論的認知過程。在人工智能領域，推理是智慧系統的核心能力之一，決定了系統如何處理資訊、形成判斷、以及產生決策。

本計劃中的「推理」不是狭義的邏輯推導，而是更廣義的**思考與規劃過程**。系統需要具備能力：
- 理解複雜問題的結構
- 將問題拆解為可管理的單元
- 探索多種可能的解決路徑
- 在不確定性中做出合理判斷

---

## 推理的類型

### 演繹推理 (Deductive Reasoning)

從一般性的原則或前提，推導出特定結論的推理方式。如果前提為真，結論必然為真。

```
前提：所有的人都會死（普遍原則）
前提：蘇格拉底是人
結論：蘇格拉底會死
```

在 Evolution Reasoning Tool 中，演繹推理用於：
- 從高層次約束（約束條件）推導出具體的執行步驟
- 從確定的目標反推起始條件

### 歸納推理 (Inductive Reasoning)

從特定的觀察或實例，總結出一般性原則的推理方式。結論具有概率性，不是絕對確定。

```
觀察：這隻天鵝是白色的
觀察：那隻天鵝也是白色的
結論：所有天鵝都是白色的
```

在 Evolution Reasoning Tool 中，歸納推理用於：
- 從多個案例中總結出共同的模式
- 從實驗結果中歸納出新的假說

### 溯因推理 (Abductive Reasoning)

又稱反向推理（Reverse Reasoning）。從觀察到的結果反推最有可能的原因或解釋。

```
觀察：草地是濕的
假設：昨晚下雨了
```

這是 Evolution Reasoning Tool 的核心推理方式。系統從**已知的終點（Step 5）反向回推**，確定：
- 為了達到這個終點，需要什麼條件？
- 這些條件如何影響前面的步驟？

### 類比推理 (Analogical Reasoning)

根據兩個事物的相似性，將一個事物的知識遷移到另一個事物上。

```
A 有屬性：X, Y, Z
B 有屬性：X, Y
推論：B 可能也有屬性 Z
```

在 Evolution Reasoning Tool 中，類比推理用於：
- 將已解決問題的經驗應用到新問題
- 從相似的約束條件預測可能的結果

## 為什麼需要結構化的推理框架？

人類的推理過程往往是隱性的，我們可能在不知不覺中進行了大量的假設、跳躍、和省略。當問題簡單時，這種方式運作良好。但當問題變得複雜時，隱性推理會導致：

- **盲點**：忽略重要的約束條件
- **矛盾**：前後不一致的結論
- **遺漏**：跳過重要的中間步驟
- **混亂**：多條路徑交織，無法看清全局

Evolution Reasoning Tool 的目標是將推理過程**外部化**和**結構化**，讓我們能夠：
- 看見整體的推理結構
- 識別可能的問題
- 與 AI 共同優化推理路徑

## 推理與圖狀結構

在 Evolution Reasoning Tool 中，推理的結構不是線性的鏈，而是**圖狀的網絡**。這是因為：

1. **多終點約束**：同一個行動可能同時滿足多個約束條件
2. **共同依賴**：多個行動可能共享依賴於同一個上游節點
3. **循環影響**：某些節點的變化可能反向影響上游決策

圖狀結構允許這些複雜關係被清晰表達，而不是被迫簡化為一條直線。

## 節點與推理

在 Evolution Reasoning Tool 中，每一個離散的推理單元被稱為一個**節點（Node）**。節點代表：

- 一個命題或陳述
- 一個約束條件
- 一個行動步驟
- 一個假設或猜想

節點之間透過**邊（Edge）**連接，邊代表推理關係或因果關係。

## 發散與收斂中的推理

### 發散階段 (Diverge)

系統主動探索多種可能的推理路徑。這是一個**生成性**的過程，重點是：
- 產生多元的假設
- 不急於評判對錯
- 保持選項的開放性

### 收斂階段 (Converge)

系統評估並選擇最有價值的推理路徑。這是一個**判斷性**的過程，重點是：
- 評估各路徑的可行性
- 識別潛在風險和衝突
- 鎖定最佳解決方案

這兩個階段交替進行，形成一個**探索-評估-精煉**的循環。

---

## 信心度 (Confidence)

在推理過程中，系統需要對自己的推論給出**信心度**評估。信心度反映：

- 前提的真實性有多高
- 邏輯連結有多強
- 過去相似案例的成功率

信心度是**動態調整**的，隨著新資訊的加入而改變。當信心度足夠高時，系統可以觸發收斂。
