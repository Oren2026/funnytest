## 多主題並行

### 概念

同一個 Evolution 實例可以同時追蹤多個獨立主題軌跡。

### 實作

```rust
struct MultiTopicGraph {
    graphs: HashMap<TopicId, Graph>,
    active_topic: TopicId,
}

enum TopicId {
    Main(String),      // 主要討論主題
    Sub(String),       // 子主題
}
```

### 行為

- 使用者可以「分支出」新主題
- 各主題獨立收斂/發散
- 可以切換 active topic

## 目前最大的問題

從「知道」到「做到」的鴻溝

- 工具是「完美的計畫設計師」，但缺乏外部執行與回饋驗證循環（Execution & Feedback Loop）
- 目前只能生成 Tool Call，無法自動執行並根據結果調整推理路線
- 需要從「自動測試工程師」升級
