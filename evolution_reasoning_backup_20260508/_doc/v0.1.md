## 功能範圍

### 必須完成（Must Have）

#### 1. 核心資料結構

```rust
// 節點
struct Node {
    id: String,              // UUID
    step: i32,              // 步驟編號（1, 2, 3, 4, 5...）
    content: String,         // 節點內容描述
    weight: f64,             // 權重（影響上游）
    confidence: f64,         // AI 信心度（0.0 ~ 1.0）
    complexity: f64,         // 該節點的複雜度貢獻
    parent_edges: Vec<String>, // 連入的邊 ID
    child_edges: Vec<String>,  // 連出的邊 ID
    status: NodeStatus,      // 狀態
}

enum NodeStatus {
    Draft,    // 草稿（未確認）
    Active,   // 活躍（可編輯）
    Pruned,   // 已刪除（被收斂移除）
    Locked,   // 鎖定（已確認）
}

// 邊
struct Edge {
    id: String,              // UUID
    from: String,             // 起始節點 ID
    to: String,              // 目標節點 ID
    edge_type: EdgeType,     // 邊的類型
    weight: f64,             // 權重
}

enum EdgeType {
    Reasoning,   // 推理關係
    Constraint,   // 約束關係
    Divergence,   // 分叉關係
}

// 圖
struct Graph {
    nodes: HashMap<String, Node>,
    edges: HashMap<String, Edge>,
}
```

#### 3. 複雜度計算系統

```rust
struct ComplexityBudget {
    k: f64,                      // 常數（預設 1.0）
    max_complexity: f64,          // 最大複雜度上限（預設 100.0）
    current_complexity: f64,      // 目前複雜度
}

impl ComplexityBudget {
    // 公式：Complex = a × k × m
    // a = 當前層數 - 未定義層數
    // m = 該節點的分散數量
    fn calculate(&self, a: i32, m: i32) -> f64 {
        (a as f64) * self.k * (m as f64)
    }

    fn is_over_budget(&self) -> bool {
        self.current_complexity > self.max_complexity
    }
}
```

#### 4. 閾值觸發系統

```rust
struct ThresholdGate {
    confidence_weight: f64,      // 預設 0.6 (60%)
    quantity_weight: f64,       // 數量權重
    depth_weight: f64,           // 深度權重
    threshold: f64,              // 觸發門檻
}

impl ThresholdGate {
    // 當 Complex > Threshold 時觸發收斂
    fn should_converge(&self, complexity: f64, confidence: f64) -> bool {
        complexity > self.threshold || confidence > 0.8
    }
}
```
