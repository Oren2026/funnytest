# v0.8 — Export Tools + HTTP API + stdin 外部觸發

日期：2026-05-07

---

## 版本目標

v0.8 完成三大方向：
1. **Export Tools**：graph/node/hypotheses/memory/backtrack 匯出（YAML/JSON/DSL）
2. **HTTP API**：TcpListener 實作，無額外依賴
3. **stdin 外部觸發**：接收 JSON 任務，ToolExecutor 執行

---

## 新增功能

### Export Tools（6 個工具）

| 工具 | 說明 |
|------|------|
| `export_graph(format)` | 推理圖匯出（yaml/json/dsl） |
| `export_node(node_id, format)` | 單節點匯出 |
| `export_backtrack(format)` | 回溯狀態匯出 |
| `export_memory(format)` | 長期記憶匯出 |
| `export_hypotheses(failure_id?, format?)` | 假設列表匯出 |
| `query_backtrack(resource)` | 狀態查詢端點（JSON） |

### HTTP API 端點

```
GET /                     - 狀態摘要
GET /status               - 狀態摘要
GET /backtrack/checkpoints  - 檢查點列表（JSON）
GET /backtrack/failures     - 失敗歷史（JSON）
GET /backtrack/hypotheses   - 假設列表（JSON）
GET /backtrack/summary      - 統計摘要（JSON）
GET /export/graph?format=   - 推理圖（yaml/json/dsl）
GET /export/memory?format=  - 長期記憶（yaml/json/dsl）
```

### CLI 模式

```bash
./evolution_reasoning              # REPL 互動模式
./evolution_reasoning --对话         # gemma4 對話模式
./evolution_reasoning --api [port]  # HTTP API 伺服器
./evolution_reasoning --stdin       # stdin 外部觸發模式
```

### BacktrackManager 新增

```rust
checkpoint_count() -> usize  // 檢查點計數
```

## 技術實作

### HTTP Server

- 使用標準 library `std::net::TcpListener`，無額外依賴
- 4 端點：status、backtrack/<resource>、export/graph、export/memory
- 啟動命令：`evolution --api 3015`

### stdin 外部觸發

- 接收 JSON 任務：`{"task": "...", "context": "..."}`
- 透過 ToolExecutor 執行
- 需要 gemma4 模型（gemma4_required 模式）

### Export 格式

**JSON**：
```json
{
  "node_count": 2,
  "nodes": [...],
  "edges": [...]
}
```

**YAML**：
```yaml
node_count: 2
nodes:
  - id: "..."
```

**DSL**：
```
graph {
  node("...", weight=0.8)
}
```
